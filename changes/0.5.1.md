<p>Searching any admin list was a 500 on MySQL and MariaDB. <code>LIKE ? ESCAPE '\'</code> is an unterminated string literal there: the engine reads the backslash inside the literal as an escape of the closing quote and runs on into the rest of the statement.</p>

<p>The backslash cannot be written once for both engines. MySQL wants <code>'\\'</code> and SQLite &mdash; what the test suite runs on &mdash; reads that as two characters and refuses it, which is exactly why the tests passed and the release did not. <code>Criteria::SEARCH_ESCAPE</code> is <code>!</code> instead, a character neither dialect touches, and <code>Criteria::like()</code> builds the whole condition so that no source spells the clause itself. <code>CriteriaTest</code> pins the SQL shape, which is the half a SQLite-backed integration test cannot see.</p>

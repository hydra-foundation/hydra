The second piece of M3, Publishing: what a public site owes search engines, link previews and feed readers, in a new package, `hydrakit/seo`. One `Meta` value prints a page's title, description, canonical URL and the Open Graph and Twitter tags a preview reads; `Sitemap` and `AtomFeed` build `sitemap.xml` and an Atom feed from plain lists. Everything is escaped once, in the package, and every URL it prints is absolute. The skeleton's home page carries its meta, and every page that passes none (sign-in, the admin) now asks not to be indexed.

It is 0.24.0 because it adds a package and `Responder::xml()`. Nothing was taken away.

## Upgrading

- **The skeleton:** `views/layouts/base.php` now prints a page's `$meta`
  when the controller passes one, and otherwise its own `<title>` plus
  `<meta name="robots" content="noindex">`. If you copy the new layout,
  pass a `Meta` (`$site->page(...)`) from every page you want in search
  results, or it drops out of them. Add `"hydrakit/seo": "^0.24"` to your
  `composer.json` first; the skeleton binds `SiteMeta` from `APP_URL`, which
  must be the scheme and host alone, with no trailing slash.

## HTTP

- `Responder::xml($body)` answers with `application/xml; charset=utf-8`, or the
  type given (`application/atom+xml` for a feed), so a sitemap or feed
  controller is one line.

## SEO

- A new package, `hydrakit/seo`. `SiteMeta` holds what every page of a site
  shares (its base URL, its name, a default share image) and makes one `Meta` per
  page: `$site->page('Resume', 'What it says', '/resume')` prints the `<title>`,
  the description, the canonical URL, and the Open Graph and Twitter tags a link
  preview reads, from `<?= $meta ?>` in the layout. Every value is escaped once,
  in the package, and every URL it prints is absolute; a base URL with a path or
  a trailing slash, or a page path that is not from the site root, is refused
  with a message naming the fix.
- `$site->article(...)` does the same for a post, adding its dates, its tags and
  its own share image; `withNoIndex()`, `withFeed('Writing', '/feed.xml')` and
  `withTitle('Name', format: false)` return a changed copy. A description is
  collapsed to one line and cut on a word at 200 characters, since front matter
  is written without counting.
- `Sitemap` builds `sitemap.xml` from paths and the time each last changed:
  absolute `<loc>`s, `<lastmod>` in UTC, no `priority` or `changefreq` (Google
  ignores both). A path added twice is listed once, with the later time, and
  past 50,000 URLs it refuses rather than write a file crawlers reject.
- `AtomFeed` builds an Atom 1.0 feed from its details and a `FeedEntry` per
  post: each entry's URL is its id, entries come out newest first, and the feed
  takes the newest entry's time. Content goes in as escaped HTML rather than
  CDATA, so a post containing `]]>` cannot break it.

## The skeleton

- The home page passes a `Meta`, so it has a canonical URL and preview tags;
  every page without one keeps its title and says `noindex`.
- `AppServiceProvider` binds `SiteMeta` from `APP_URL` and `APP_NAME`, with
  the 512×512 icon as the default share image; an `APP_URL` with a path or a
  trailing slash fails with an error naming `APP_URL`.
- `public/robots.txt` keeps crawlers out of `/admin`, with a commented
  `Sitemap:` line for an app that adds one.
- `AGENTS.md` says how to give a page its meta.

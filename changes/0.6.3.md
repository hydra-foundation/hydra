<p>Everything here adds, and nothing is taken away, so it is a patch and <code>^0.6</code> picks up the framework half with a plain <code>composer update</code>. The rest is the skeleton&rsquo;s own files; copy what you want from it.</p>

<h3>Upgrading from 0.6.2</h3>

<p>Nothing is required. <code>hydrakit/core</code> now requires <code>composer-runtime-api ^2.0</code>, which every Composer 2 install already provides. Only a project still on Composer 1 will notice.</p>

<h3>Versions</h3>

<p><code>Hydra\Core\Versions</code> answers two questions from the two places that know the answers:</p>

<ul>
  <li><code>hydra()</code> is the version Composer installed of <code>hydrakit/core</code>.</li>
  <li><code>application()</code> is <code>git describe --tags --always</code> in your project: a tag, a tag plus how far past it (<code>v1.2.0-3-g4652f0d</code>), or a bare commit. It is <code>null</code> with no repository or no commits. A project made with <code>create-project</code> starts with no history, so it has no version until you give it one; Hydra&rsquo;s version is not yours.</li>
</ul>

<p>The skeleton shows both under the sign-in form and in a new footer at the bottom of the admin. The admin&rsquo;s shell takes an optional <code>footer</code> and renders it below the frame, so navigating never re-renders it; pass it from your <code>layouts/admin</code>, or pass nothing and there is no footer.</p>

<p>The skeleton&rsquo;s php image now sets git&rsquo;s <code>safe.directory</code> system-wide. FPM runs as <code>www-data</code>, and a root-only setting left it refusing the bind-mounted repository, so the application&rsquo;s version silently went missing.</p>

<h3>Audit</h3>

<p>Saving an edit form without changing anything no longer writes an audit row. A blank password still counts as untouched, the way the form treats it. The write and its <code>RowUpdated</code> event are unchanged, so the log line is still there; only the audit listener, which is the skeleton&rsquo;s, now skips an update that moved nothing.</p>

<p>The skeleton&rsquo;s Account and Security settings stacked every form they had down one page. Account showed five inputs and two submit buttons, with nothing to say which button went with which fields, and turning off two-factor sign in looked like any other form except for the colour of its button. Each setting is now a row that names it, shows its current value and opens the one form that changes it, in place. One opens at a time, and a form that comes back with an error opens itself again. General reads the same way. Appearance and Regional were already one decision a page and are unchanged.</p>

<p>Nothing was removed, so this is a patch. <code>admin.css</code> gains the rows&rsquo; classes and asks for three theme tokens it did not before: <code>--danger-line</code>, <code>--danger-wash</code> and <code>--ok</code>. Only the new classes use them, so a theme without them renders as it did until it shows a settings row.</p>

<h3>Upgrading</h3>

<p>Nothing is required. To take the new screens, copy <code>general.php</code>, <code>account.php</code> and <code>security.php</code> from the skeleton&rsquo;s <code>views/admin/settings</code>, and define the three tokens in any theme that lacks them; <code>ThemeContractTest</code> names the ones that do. No route or controller changed, and every form keeps its <code>id</code> and <code>intent</code>.</p>

<h3>Settings rows</h3>

<p><code>.settings-rows</code> is a 34rem column, the width the theme picker already had. A row that only reads is a <code>.settings-row</code> holding a <code>.settings-row-static</code>. A row that changes something is a <code>&lt;details class="settings-row"&gt;</code> whose summary holds the label, the value and a <code>.settings-row-action</code> reading Change, or Cancel while it is open, and whose form is a <code>.settings-row-form</code>. Giving every row on a page the same <code>name</code> is what keeps one open at a time; there is no script. <code>.is-danger</code> marks the row whose action leaves the account weaker, and <code>.settings-state</code> is the on and off dot. In a frame narrower than 36rem the value drops below its label.</p>

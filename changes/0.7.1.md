<p><a href="/docs/ethos.html#fakes">The ethos</a> went up with 0.7.0 promising a contract, a driver and a fake in the same commit, and admitting three packages that did not keep it. This closes the gap. Everything here is a new class or a new test, and nothing published changed shape, so it is a patch.</p>

<h3>The three that were missing</h3>

<ul>
  <li><strong><code>Hydra\Database\Testing\FakeConnection</code></strong> records every statement and fails on demand &mdash; <code>failOn()</code> for statements containing some SQL, <code>failAll()</code> for a database that is down. The statements still run, against in&#8209;memory SQLite unless another connection is given. <a href="/docs/database.html">The database</a> has the detail.</li>
  <li><strong><code>Hydra\View\Testing\FakeView</code></strong> renders templates the test defined and records every render, so a controller test asserts on the template, the data and the layout flag. An undefined name throws. <a href="/docs/templates.html#testing">Templates</a> has an example.</li>
  <li><strong><code>Hydra\Auth\Testing\FakeGuard</code></strong> is signed in as whoever it is told, with <code>FakeUser</code> for a test that does not care who. Nine guards had been written by hand across the framework, the skeleton and the website.</li>
</ul>

<h3>Contracts that had nothing to hold them</h3>

<p>Three contracts had an implementation, some had a fake, and none had a case saying what either owed its callers. <code>GuardContractTestCase</code> holds <code>check()</code>, <code>user()</code> and <code>id()</code> to agreeing. <code>OutputContractTestCase</code> holds a command&rsquo;s output to dropping nothing and to answering an unattended question with its default. <code>ContainerContractTestCase</code> states what every service provider assumes: a factory runs on first use, runs once, may reach for a binding registered after it, and is replaced by a later binding even once resolved. PHP&#8209;DI passes it, and so does the new <code>Hydra\Core\Testing\FakeContainer</code>, which replaces fourteen containers the test suites had each written for themselves.</p>

<h3>Found by doing it</h3>

<p><strong>A test passing for the wrong reason.</strong> The throttle provider&rsquo;s test bound a limit of one and then registered the provider, which binds its own. Under PHP&#8209;DI the later binding wins and the test&rsquo;s limit is never seen; the hand&#8209;written container kept the first one, so the test passed. Several of the fourteen disagreed with the real container in the same way, and one ran factories at registration.</p>

<p><strong>Two guards that contradicted themselves.</strong> In the skeleton&rsquo;s tests, <code>check()</code> answered yes while <code>user()</code> answered nobody &mdash; exactly the state the guard contract now rules out.</p>

<p><strong>Fakes nobody measured.</strong> Coverage had excluded all of <code>src/Testing</code>, a rule written for the contract cases that also hid every shipped fake. <code>FakeOutput</code>, which every command test leans on, had no test of its own. Only the contract cases are excluded now, the fakes are tested, and the floors were raised to match. Counting them also exposed an Infection exclude that had never matched anything, which is fixed.</p>

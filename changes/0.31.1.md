A release found by a naming pass over an app built on the skeleton. Two of the skeleton's classes did not have the names its own generators give, and `AGENTS.md` left six folders out of its map and said every SQL statement lives in a repository, which the admin's sources and dashboard widgets do not do and are not meant to. The classes are renamed and the guide now matches the tree.

It is a patch: nothing a package exports changed. The renamed classes live in the skeleton, which an application copies once rather than takes from Composer, so an app keeps working as it stands and renames them only if it wants the new names.

## Upgrading

- **The skeleton:** An app made from the skeleton that kept these classes renames them as it merges the release: `src/Listeners/PublishQueueChanges.php` and `src/Admin/Sources/ScheduledRunsSource.php`, their tests, and where `AppServiceProvider` and `ScheduledRunsModule` name them.

## The skeleton

- Two classes take the names the generators give: the listener `PublishQueueChanges` is `PublishQueueChangesListener`, and the source `ScheduledRunsSource` is `ScheduledRunSource`. `AGENTS.md` lists the folders it left out and no longer says every SQL statement is in a repository: admin sources and dashboard widgets write their own.

<p>Four colliding types renamed, PHPStan raised to level 6 with the generics filled in, and a comment pass across every package.</p>

<div class="note warn">
  <span class="label">The release that set the rule</span>
  <p>It first went out as <code>v0.3.4</code> and had to be pulled off Packagist. Removing <code>ContentSecurityPolicy</code>, <code>Http\Input</code>, <code>Http\Route</code>, <code>AbstractSession</code> and <code>SessionInterface::getFlash</code> breaks every consumer on <code>^0.3</code>, and <code>create-project</code> at 0.3.3 resolved straight into it. A removal is a minor.</p>
</div>

<p>Two tools came out of it. <code>bin/api-surface.php</code> reports what a tag removes and <code>bin/release.sh</code> refuses a patch that removes anything. And the two repositories are no longer tagged together: the framework is tagged first, Packagist is waited on, then the skeleton is locked and verified before it gets its own tag &mdash; which is how the skeleton&rsquo;s lock went stale in the first place.</p>

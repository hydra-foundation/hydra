The admin fits a phone. List screens, the Settings screens and the dashboard used to be wider than a narrow screen and scrolled sideways; they now wrap or narrow instead. A storage driver's contract test also stops failing about one run in a hundred.

This is a patch release because both are fixes and nothing was removed or changed shape. An app upgrades with `composer update` inside `^0.10`.

## The admin

- On a phone, the admin no longer scrolls sideways. A list screen's toolbar
  wraps its buttons under the search, the Settings category strip wraps onto a
  second row, and the dashboard's loading placeholder narrows to fit.

## The filesystem

- `StorageContractTestCase` no longer fails at random. Its "stored as `.bin`"
  case used random bytes, and libmagic reads about one random string in a
  hundred as a type it knows. It now uses fixed bytes, so a driver's contract
  test passes or fails the same way every time.

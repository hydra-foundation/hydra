<p>A skeleton-only release: the framework is unchanged since 0.6.1, and its packages are tagged 0.6.2 only so that the two repositories keep one version between them. Nothing was removed, so it is a patch. An existing application gets none of this from <code>composer update</code>, since themes are the application&rsquo;s own files; copy what you want from the skeleton.</p>

<h3>Themes</h3>

<p>A theme is one file of colour tokens in <code>public/css/themes/</code>, and the picker under Settings &rsaquo; Appearance lists whatever is in that directory. Five join paper and graphite:</p>

<ul>
  <li><strong>Tokyo night</strong>, <strong>Nord</strong> and <strong>Kanagawa</strong>, from their neovim palettes.</li>
  <li><strong>Rose pine dawn</strong>, a second light theme.</li>
  <li><strong>Phosphor</strong>, an amber monochrome terminal. Brightness carries the hierarchy, and only danger and success break from the amber.</li>
</ul>

<p>Every text colour clears WCAG AA against the backgrounds it is used on. Where a palette&rsquo;s own colour did not, it was lightened or deepened with its hue kept: Nord&rsquo;s red, and Dawn&rsquo;s iris, love and gold.</p>

<h3>Auto</h3>

<p><strong>Auto</strong> paints the admin in paper from 08:00 to 18:00 and in graphite outside those hours, in the timezone set under Settings &rsaquo; Regional. It is saved as the choice and resolved to a palette on each full page load. A signed-out page, which has no timezone to read, stays on paper.</p>
